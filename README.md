# AURA Mars 🔴

**Augmented Understanding & Research Assistant for Mars Exploration**

A research-support tool that answers Mars exploration questions using Retrieval-Augmented Generation (RAG), grounded entirely in real scientific sources with calculated confidence scores.

## Key Principles

- **Grounded answers only** — every claim traces to a retrieved source document
- **Calculated confidence** — scores are computed deterministically in Python, never generated by the LLM
- **Transparent unknowns** — the system explicitly surfaces what is not known, disputed, or unverified
- **100% local & free** — runs on Ollama + ChromaDB + Python with zero cloud API costs

## Tech Stack

| Layer | Tool |
|-------|------|
| LLM | Ollama — gemma3:4b |
| Embeddings | Ollama — nomic-embed-text |
| Vector DB | ChromaDB (local, file-based) |
| PDF Extraction | PyMuPDF |
| Scoring | pandas, numpy, scikit-learn |
| UI | Streamlit |
| Charts | Plotly |

## Quick Start

### Prerequisites

- Python 3.10+
- [Ollama](https://ollama.ai/) installed and running

### Setup

```bash
# 1. Clone the repo
git clone <repo-url>
cd AURA-MARS

# 2. Create virtual environment
python -m venv venv
venv\Scripts\activate  # Windows
# source venv/bin/activate  # macOS/Linux

# 3. Install dependencies
pip install -r requirements.txt

# 4. Pull Ollama models
ollama pull gemma3:4b
ollama pull nomic-embed-text

# 5. Copy environment config
copy .env.example .env  # Windows
# cp .env.example .env  # macOS/Linux

# 6. Verify setup
python scripts/verify_setup.py

# 7. Add PDFs to data/raw_pdfs/ and run ingestion
python scripts/ingest_cli.py --dir data/raw_pdfs/

# 8. (Optional) Enrich source metadata with real citation links
# Looks up each paper's title on arXiv / Semantic Scholar (free, no API
# key) and fills in year/authors/url/pdf_url/doi. Never invents a link:
# sources with no confident match are left as-is.
python scripts/enrich_metadata.py

# 9. (Optional) Download real NASA SPICE ephemeris data
# Upgrades the Journey to Mars / Mission Planner tabs' planet positions
# from validated analytical orbit math to real NASA/JPL ephemeris data.
# ~31MB one-time download. The app works fully without this step.
python scripts/download_spice_kernels.py

# 10. Launch the app
streamlit run app/app.py
```

Note: retrieval, generation, and confidence scoring — the core RAG
pipeline — are always 100% local. Steps 8 and 9 above are optional,
one-time enrichment steps that call external network APIs (arXiv/
Semantic Scholar for citations, NASA/NAIF for ephemeris data).

## Architecture

```
User Question → Retrieval (ChromaDB) → Evidence Scoring (Python)
    → LLM Generation ×4 (gemma3:4b) → Consistency Scoring (Python)
    → Confidence Fusion → Verification Pass → Structured Output
```

**Architectural rule**: The LLM never invents a confidence number. All scoring is deterministic Python. The LLM's only jobs are: (1) synthesize an answer from provided evidence, (2) explain a score it is handed, (3) verify its own claims trace to sources.

## Confidence Scoring

```
Final Confidence = (0.6 × Evidence Confidence) + (0.4 × Generation Consistency)
```

| Range | Label |
|-------|-------|
| 70–100% | High |
| 40–69% | Medium |
| 0–39% | Low |

> **Note**: This score measures how well-supported a claim is by available evidence and how stable the model's reasoning is — not objective truth.
